Notes

The app stores demo data in the browser using `localStorage`. Payments, profile edits, bookings, attendance entries, reports and training history stay saved in the same browser until local storage is cleared. The training library includes a free guided starter and ten illustrated plans; detailed plans unlock only from a simulated current-month payment record. No money is collected and this browser-only gate is not a production payment entitlement.
