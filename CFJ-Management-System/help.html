Help with your account and classes

Choose a topic below. These instructions describe the current project demonstration.

Get started

Open Account, choose Member Login, then select Login As Member to try the prefilled sample account. Use fictional details if you create a new demo account. Your website records stay in this browser.

Update my profile

On Members, find Edit Profile and Preferences. Change your details, then select Save Profile Changes. Use Logout on the profile card when you finish.

Book or cancel a class

Open Operations and find Class Booking. Filter by date, type or instructor, then choose Book. Check Your Bookings for the result. Choose Cancel on a booking to release its place. These are demo reservations, not real gym bookings.

Payments and training guides

Pay Membership records a simulated payment and displays a sample confirmation. No money is charged or message sent. Library uses your selected goal and demo payment status to show sample guides.

Staff and administrator access

Use the separate Staff Login or Admin Login page. Staff use Staff Desk and administrators use Admin Reports. Use the footer Logout link before changing roles.

Fix a problem

I cannot sign in

Check your role, email and password. An account created in another browser is not shared with this one. Hosted sign-in and email verification are still being developed.

No classes appear

Choose All classes and All instructors, and clear the date filter. Check Your Bookings if you have already requested a class.

The profile service rejects my save

If another client changed the profile, select Load profile before editing again. For access or connection errors, ask the developer to check the service. Do not share access tokens in screenshots.

The website and app show different data

The main website uses browser records. Android preferences are local, and the separate Oracle profile page uses the API. Full integration is still in progress.

Android preview

Home introduces the app. Classes opens timetable information. Settings saves your name and training goal locally. The debug profile connection has separate load and save buttons. Phone testing and hosted authentication are still outstanding.

Report a problem

Tell the project team which page you used, the steps you took and what happened. Add a screenshot with passwords and tokens hidden.
