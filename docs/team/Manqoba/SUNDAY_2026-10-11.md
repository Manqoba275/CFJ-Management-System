## Findings and fixes

- Duplicate configured identity IDs could associate distinct tokens with the same private records. The service now rejects duplicate IDs and missing tokens; a regression test verifies startup rejection.

- Local Android lint failed because the Windows SDK drive colon in ignored `local.properties` was unescaped. Corrected the PC-specific file and documented proper escaping without committing the local path.
- Browser review found the service token label omitted admin access and report denial displayed a raw error code. Updated both to plain language.
