## Changes

- Added GET/PATCH /api/v1/me with a token-selected synthetic profile, validation, serialized version checks and atomic local persistence. The local server binds to loopback only; it must not be publicly deployed.
- Added debug Android Settings controls to load/save the profile. Network work runs off the UI thread; tokens are not saved or logged. Only successful responses update local preferences, and stale/failed writes require reloading.
- Added endpoint-security unit tests and an optional device smoke test. Cleartext access is limited to three local addresses in debug builds; release builds hide the manual connection panel.
- Added run instructions and API contract in backend/PROFILE_API.md. Standard local preference saving remains separate.
