About this demonstration

Independent student work

This is a proposed management system created for assessment. CFJ has not agreed to replace or integrate its existing Octiv service. Links marked official take you to the real gym's website; demo actions do not contact the gym.

Accounts and privacy

Use fictional names and details, and a password used only for this demo. Account details and example records are stored in this browser's local storage. Demo passwords are not protected like production passwords. Email ownership is not verified, password recovery and Google sign-in are not connected, and signing in here does not create a CFJ membership.

Clearing this site's browser storage removes local changes and restores sample data on the next visit. Other browsers and phones do not share your demo changes. Do not enter medical details, real passwords or payment information.

Bookings, payments and messages

All demo class places, people and payment records are fictional. No money is collected and no confirmation email or SMS is sent. Membership information on the homepage describes CFJ's published options; eligibility rules and prices must be confirmed with the gym.

Project technology

The website uses HTML, CSS and JavaScript. The Android app uses Kotlin. A separate Node.js development API supports shared workflows locally. Oracle is the planned business database and Firebase Authentication is the proposed identity service; neither is connected to this public demo.

Real enquiries

Use CFJ's official contact page for genuine membership enquiries and its official timetable for booking information.
